What each holding really is

One row per ticker per sector. A holding that belongs entirely to one sector needs a single row with weight 1. To split a holding, give it several rows whose weights add up to 1 — for example MCX at 0.5 to {{ metals_sector }} and 0.5 to Financials, because a commodity exchange's earnings partly track bullion volumes. Weights that do not add to 1 are scaled to fit, and you will be told.

Sector splits; asset class does not. Use the same asset class on every row for a ticker. And note that {{ metals_sector }} is the one sector name the warnings know by name — every holding's weighted share of it is added up for the combined bullion check.
